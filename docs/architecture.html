ASM — Skill Management Architecture

Skills 从来源进入 Registry，通过 Sync Engine 以 symlink 部署到 Agent 目标目录

Skill 来源

  • • asm create 创建自有 core skill
  • • asm add --url 添加远程 vendor (git submodule)
  • • asm add --path 添加本地 vendor (symlink)
  • • asm scan --adopt 纳管已有 skills

同步机制

  • • SHA256 哈希增量检测，无变更时跳过
  • • 通过 symlink 部署，修改注册表即时生效
  • • .asm-managed.toml 追踪所有权
  • • 只清理自己创建的 symlink，不动其他文件

双层作用域

  • • 用户级 → ~/.claude/skills/ + ~/.agents/skills/
  • • 项目级 → .claude/skills/ + .agents/skills/
  • • 项目通过 .asm/skills.toml 声明所需 skills
  • • 同时支持 Claude Code 和 Codex 两类 Agent
